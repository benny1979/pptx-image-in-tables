Cell Images

A PowerPoint add-in that puts images inside table cells, with the cell's text reserved to one side — the thing Word tables do and PowerPoint's cannot.

Install

Nothing to run. Download manifest.xml and sideload it:

  • PowerPoint on the web — Insert ▸ Add-ins ▸ Upload My Add-in. Easiest, and not blocked on a managed machine.
  • Windows — put the file in a shared folder, add that share under File ▸ Options ▸ Trust Center ▸ Trust Center Settings ▸ Trusted Add-in Catalogs, restart PowerPoint.
  • Mac — copy it to ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef/

It then sits on the Home tab as Cell Images.

Requirements

Microsoft 365 PowerPoint with PowerPointApi 1.9 — Windows build 2508+, Mac 16.100+, or PowerPoint on the web. Not available on volume-licensed perpetual or LTSC Office, and not on iPad. The add-in checks at runtime and says what is missing rather than failing silently.

Decks you produce open correctly anywhere: the output is an ordinary PowerPoint table, so old perpetual Office presents and prints it fine.
